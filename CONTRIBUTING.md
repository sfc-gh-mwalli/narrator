# Contributing

Thanks for your interest — this repository is published **as-is** and is
intentionally **read-only**.

- Issues, discussions and pull requests are **not** accepted here.
- Please **fork** it if you would like to adapt it for your own use. The MIT
  licence permits that freely; see `LICENSE`.
- **No support is provided.** It is a reference implementation, not a product.

If you fork it, the two things most likely to need changing are the Snowflake
account and warehouse names in `snowflake.yml`, `sql/` and
`worker/push-to-spcs.sh`. The README covers this under "Working from a fresh
clone".
